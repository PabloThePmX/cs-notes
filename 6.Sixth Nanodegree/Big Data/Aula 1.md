# Aula 1

* Big data é um termo recente e significa dados multivariados e de elevada dimensão, geralmente criadas em tempo real.
  * Apresentam crescimento exponencial.
* Quanto mais dados são gerados, maior é o esforço para extrair as informações.
* Big Data é sobre valor e significado que podem ser extraído dos dados.
* Data Never Sleeps.
* Países maiores costumam ter uma boa infra pra conseguir suportar tantos usuários.
