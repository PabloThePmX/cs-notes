# Aula 7

## Oratória
* O movimento é o que costuma chamar mais a atenção.
  * Não usar demasiado.
* Fundo claro com fonte escura, ou o contrário.
* Destaque os tópicos.
* Se deu um branco, não insista tanto em lembrar, e retome o que tem nos slides.
  * Os slides também servem para tentar lembrar-nos.
* Vícios de linguagem.
  * Tentar fazer pausas para impactar.
* Colocar frases como citações diretas.
* Colocar fontes em imagem com dados, tipo: fluxogramas, gráficos, etc.
  * Se for imagem apenas estética, não precisa.
* Colocar referências das imagens no final do slide também.
* Gesticular.
* Olhe para os ouvintes.
* Sinalizar que a apresentação está finalizando, usando termos ou tom de voz para dar indiretas quanto a isso.
* Não desmerecer o próprio trabalho.
