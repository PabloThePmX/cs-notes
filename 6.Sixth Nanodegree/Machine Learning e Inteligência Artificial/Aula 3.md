# Aula 3

* Variáveis quantitativas e qualitativas.
  * Numéricas e descritivas.
* Quantitativas
  * Continuas e Discretas.
* Qualitativas
  * Ordinais e Nominais.
* Usar o parâmetro `inplace` no `pd` para atualizar o dataframe.
* Métodos `head()` para ver os n primeiros e `tail()` para ver os n últimos.
* Usar `.str` para transformar em uma string.
* Para filtrar, usar `df[FILTRO BOOLEANO]`.
* Usar `&` para fazer AND.
  * O `~` é o NOT.
* Faz operação `bitwise` com vários filtros, por isso colocar `()` ao redor de cada condição.
  * `df[(FILTRO) A & (FILTRO B)]`.
* Usar `apply()` para aplicar algo, como uma função.
  * Ele vai enviar a informação da coluna que usa esse método.
