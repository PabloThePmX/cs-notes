# Aula 10

## Sistemas Lineares

* Sistemas lineares trazem o valor de x e y.
* Para descobrir um dos valores, fazer o calculo de cima pra baixo, do primeiro item pelo segundo.
  * As vezes vai cortar pra sumir uma das incógnitas.
    * Pois precisa ficar sempre com apenas uma.
  * Se não corta, precisa multiplicar para que cheguem um valor para ser cortado
    * Multiplica a linha inteira.
    * Vai fazer um sistema "novo".
* Se zerar, e for verdadeiro, quer dizer que as duas retas estão no mesmo lugar, tendo todos os seus pontos em comum.
  * Se der falso, o sistema é impossível, sendo que as retas não se cruzam nunca, sendo retas paralelas.
* Ou seja, se o sistema funciona, quer dizer que as retas se cruzam, se for zerado mas verdadeiro, elas possuem infinitos pontos, e caso for zerado e falso, elas são paralelas e não se cruzam.
* Os de tres dimensões possuem x, y e z.

## Função Quadrática

* Tem x ao quadrado.
* Concavidade para cima ou para baixo.
  * Quando o número que acompanha o x^2 for positivo, é pra cima, e negativo para baixo.
    * Para baixo tem valor máximo, e para cima tem valor mínimo.
* A parabola vem e vai para o infinito.
* Virado (concavidade) para baixo, tem valor mínimo, e para baixo um valor máximo.
* `x = -b/2a` para pegar o valor de x (vértice).
  * Depois trocar o x na função quadrática para pegar o valor de y.
