# Aula 1

## ML

* Machine Learning é probabilístico
  * Vai pegar respostas passadas e dados para criar regras (lógicas matemáticas).
  * Recebe milhares de registros históricos.
  * Diferente do determinístico, que tem regras pré programadas (if/else).
  * Em cima de dados tabulares.
* Eng de IA != Eng de ML.
* IA é a área inteira.
  * Na sub-área tem ML.
    * Na sub-área tem DL (Deep Learning), com redes neurais.
      * Na sub-área tem IA generativa.
* Pouco é algoritmo (apenas 5%, tuning), a maioria é infra.
* Monitoramento contínuo (MLOps).
  * Vigia a degradação inevitável.
* ML é um processo de nutrição e adaptação contínua.
* Os dados são o motor do ML.
* Ciclo: Escopo e objetivos, engenharia de dados, desenvolvimento do modelo e monitoramento (MLOps).
* A linguagem de negócio precisa virar linguagem técnica.
* Sem dados de alta qualidade, o modelo falhará (garbage in, garbage out).
* Feature Engineering.
* Data leakage.
  * Incluir acidentalmente informações do futuro no treinamento.
* No treinamento existe tentativa e erro com correção contínua.
* Tipos de complexidade
  * Underfitting (muito simples).
  * Sweet Spot.
  * Overfitting (ao invés de detectar um padrão, memoriza os ruídos).
* Ruído é aquilo que não tem um padrão definido.
* Bias-Variance.
* Vai ter erros, e precisamos usa-los para melhorar o sistema.
  * A acurácia geral engana (falso negativo, falso positivo, etc)
* Falhas silenciosas: Data drift e Concept Drift.
* A regra dos 25%, distribuindo equilíbrio entre:
  * Engenharia de Software.
  * Engenharia de Dados.
  * Modelagem/Matemática.
  * Entendimento do Negócio.
