## MCP e Integrações
* Uma conexão deve responder a uma necessidade.
* Um padrão aberto de conexão.
  * Um contrato disponível para a IA.
    * Ou seja, um protocolo.
  * Uma linguagem comum para conectores de IA.
* Conversa com um servidor.
* A conexão amplia o contexto disponível, mas não garante uma resposta correta.
* Reduz o custo dos tokens (mas depende do fluxo).
  * Assim como o RAG.
* `Codegraph` para indexar o repositório.
* Da pra criar um MCP local.
  * Mas verificar a autenticação, para não permitir que qualquer um possa se conectar.
  * Ter uma URL para um personalizado.
* Host -> Cliente MCP -> Servidor MCP.
* As três capacidades do MCP: Tool, resource, prompt.
* MCP para ERP (Case `Senior ERP`).
* O MCP tem ferramentas, que seriam quase como endpoints.
* É a IA que aplica os filtros e chama o MCP.
